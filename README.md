# Corrida entre Cores

## Descrição

**Corrida entre Cores** é um jogo divertido e interativo onde os jogadores competem girando um dado para sortear uma cor. Cada cor avança uma casa no tabuleiro, e o primeiro a chegar ao final vence. Este jogo é uma ótima maneira de se divertir com amigos e familiares!

## Objetivo do Jogo

O objetivo do jogo é ser o primeiro a chegar ao final do tabuleiro, movendo sua cor de acordo com os resultados do dado.

## Regras do Jogo

1. Cada jogador escolhe uma cor.
2. Em cada turno, um jogador gira o dado.
3. O número sorteado no dado determina quantas casas a cor do jogador deve avançar.
4. Se uma cor já estiver na casa de destino, o jogador deve esperar a próxima rodada para tentar novamente.
5. O primeiro jogador a alcançar a última casa do tabuleiro é o vencedor!
